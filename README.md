# Avalon Online (private-use)

友人同士で遊ぶための、リアルタイム同期型 Avalon 風 Web アプリです。Node.js 以外の外部依存はありません。

## 実装済み

- ルーム作成 / 5文字のルームコード参加
- 招待リンクのコピー
- 同じブラウザからの自動再接続
- 5〜10人対応
- Standard / Simple / Custom 配役
- マーリン、パーシヴァル、暗殺者、モルガナ、モードレッド、オベロン
- リーダーによる任務チーム提案
- 全員の承認 / 否認投票
- 任務成功 / 失敗の秘密投票
- 善陣営は成功票のみ、悪陣営は成功 / 失敗を選択可能
- 7人以上の第4任務は失敗票2票で失敗
- 任務3回成功後の暗殺フェーズ
- 5回連続チーム否認で悪陣営勝利
- 終了時の全役職公開 / 再戦
- ホストによる切断プレイヤー削除
- 秘密情報はサーバー側で管理し、各ブラウザへ必要な情報だけ送信

## 起動方法

Node.js 18 以上をインストールし、このフォルダで次を実行します。

```bash
npm start
```

依存パッケージがないため `npm install` は不要です。

PC自身では以下を開きます。

```text
http://localhost:3000
```

同じ家庭内 LAN のスマホから使う場合、たとえば PC の LAN 内 IP が `192.168.1.20` なら以下を開きます。

```text
http://192.168.1.20:3000
```

Windows ファイアウォールで Node.js の受信許可が必要になる場合があります。

## インターネット公開（Render 例）

このフォルダを GitHub リポジトリに置き、Render で Web Service として接続すれば動かせます。

- Build command: `echo "No build step"`
- Start command: `node server.js`
- Health check: `/health`
- `PORT` はホスティング側の値を自動利用します。

`render.yaml` も同梱しています。

### データ保持について

この版は個人利用で設定を簡単にするため、部屋情報をサーバーのメモリ内だけに保持します。サーバー再起動・再デプロイ・無料ホスティングのスリープ等が発生すると進行中の部屋は消えます。通常の1ゲーム単位の利用を想定しています。

## Docker

```bash
docker build -t avalon-online .
docker run --rm -p 3000:3000 avalon-online
```
